# UI 说明：行迹

- **谁在什么时刻打开**：给安排两三天周末游的人。
- **首屏任务句**：今天怎么走，才不误车。
- **主操作**：按「定出发和预约 → 排通勤与缓冲 → 带走当天路线」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：翻开的旅行路书；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：翻开的旅行路书。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给安排两三天周末游的人：用确认过的营业时间、预约截止和通勤排程；下雨或误车，只重排受影响半天。
